# UniMatch
Este repositório foi criado para fazer um projeto universitário
Nome final da APP: Uni Match Piaget

Slogan:Connect. Study. Match

Conceito

O UniMatch é uma plataforma universitária inteligente que permite aos estudantes:

conhecer colegas
encontrar parceiros de estudo
criar grupos de trabalho
interagir socialmente

Tudo isto através de:

autenticação universitária
matching inteligente
sistema de reputação académica

Problemas atuais:
dificuldade em conhecer pessoas fora da turma
problemas em encontrar colegas compatíveis para trabalhos
falta de plataformas universitárias seguras
grupos de trabalho desorganizados
excesso de perfis falsos em apps tradicionais

Solução:
verificação universitária
sistema de compatibilidade
matching por interesses académicos
criação de grupos
reputação entre utilizadores

Público Alvo:
estudantes universitários
alunos Erasmus
estudantes deslocados
caloiros

Objetivo Geral

Criar uma plataforma inteligente de networking académico e social para estudantes universitários.

Outros objetivos:
facilitar criação de grupos
melhorar colaboração académica
promover interação social segura
recomendar utilizadores compatíveis
reduzir perfis falsos

Apps semelhantes
Tinder	demasiado focado em dating
Bumble	não é académico
LinkedIn	demasiado profissional

Diferenciação do UniMatch:Pontos Inovadores

Login universitário
reduz perfis falsos

Matching académico
compatibilidade por curso/interesses

Sistema de reputação
feedback em trabalhos

Procura de grupos de estudo
foco utilitário

Ambiente fechado
apenas estudantes


O UniMatch diferencia-se por combinar:

rede social
plataforma académica
sistema inteligente de compatibilidade

num único ecossistema universitário.


Requisitos Funcionais
Utilizadores

1 — O utilizador deve conseguir criar conta
2 — O utilizador deve fazer login
3 — O utilizador deve editar perfil
4 — O utilizador deve adicionar fotografia

Matching
1 — O sistema deve permitir likes/dislikes
2 — O sistema deve gerar matches
3 — O sistema deve sugerir utilizadores compatíveis

Comunicação
1 — O utilizador deve enviar mensagens
2 — O utilizador deve receber notificações

Academico
1 — O utilizador deve procurar grupos de estudo
2 — O utilizador deve criar grupos
3 — O utilizador deve adicionar disciplinas/interesses

Reputação
1 — O utilizador deve avaliar colegas
2 — O sistema deve calcular reputação

Requisitos Não Funcionais
1 — Interface responsiva
2 — Sistema seguro
3 — Dados protegidos
4 — Tempo de resposta inferior a 2 segundos
5 — Compatível com dispositivos móveis
6 — Escalabilidade do sistema
